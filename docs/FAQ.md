## 这是什么

SaveGrab：不用下载游戏，直接把 Epic 云存档导出/还原到本地。下载见 [Releases](../../releases)。

## 常见问题

### Q：登录时为什么要粘贴一段 JSON？

Epic 只允许通过官方网页登录。登录后页面会返回一段包含 `authorizationCode` 的 JSON，
把它整段粘贴进工具即可换取一次会话。工具不接触、也不保存你的密码。

### Q：为什么我的游戏不在列表里？

工具只显示 Epic 商店元数据里配置了 `CloudSaveFolder` 的游戏——没配的游戏本来就没有云存档，
会被自动过滤掉。想确认某个游戏是否支持，可以看它的商店页有没有"云存档"标识。

### Q：导出/还原到一半失败了怎么办？

直接重试即可：已下载的分块会复用，还原时会跳过已存在的缓存。
如果一直超时，把线程数调小（比如 2），或者避开网络高峰再试。

### Q：还原后游戏提示"存档损坏"？

存档和生成它的账号绑定。请确认：

1. 还原到的是**同一个 Epic 账号**对应的存档目录（工具会自动识别账号 ID 子目录）
2. 没有把 Steam 版存档直接丢给 Epic 版（或反过来）——这两个版本需要额外处理游戏文件，
   **本工具不做这件事**，请自行判断风险

### Q：还原前需要做什么？

**先关闭 Epic 启动器里的云存档同步**，否则启动器可能用云端旧档覆盖你刚还原的文件。
工具在还原前会自动把现有存档打包备份到 `%LOCALAPPDATA%\SaveGrab\backups\`。

### Q：会收集我的账号信息吗？

不会。所有数据都在本地：登录会话保存在 `%LOCALAPPDATA%\SaveGrab\legendary\user.json`，
随时可以在软件里点「退出登录」清除。

### Q：支持哪些系统？

Windows 10/11 x64。源码是跨平台的 Python，但界面用的是 tkinter 的 Windows 风格，
macOS/Linux 未测试。

### Q：可以商用吗？

项目是 GPL-3.0-or-later，按协议使用即可；但它依赖 Epic 的非公开接口，请自行评估风险。
