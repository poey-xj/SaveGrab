# B 站视频脚本 / 大纲（草稿）

> 目标时长 5～7 分钟。软件名 **SaveGrab**。核心卖点：**Epic 官方没有「导出云存档」按钮，这个工具能直接把云端的存档拉回本地，不用下载游戏。**

## 标题候选

- 《Epic 没有导出云存档的功能？我做了个工具，不用下游戏就能把存档捞回来》
- 《重装系统前必看：Epic 云存档一键导出，死亡搁浅实测》
- 《我把 Epic 云存档扒下来了：不装游戏，直连服务器》

## 分镜

### 0. 开场（0:00–0:40）钩子

- 画面：Epic 启动器里死亡搁浅的「云存档」图标，点开只有同步开关，没有导出。
- 台词要点：
  - 「Epic 的云存档，只能同步，不能导出。想备份？官方没这个功能。」
  - 「换电脑、重装系统、或者只是想留个底，怎么办？」
  - 「今天这个工具，不下载 70G 的游戏，直接把云端存档拉回本地。」

### 1. 背景（0:40–1:30）云存档到底是什么

- 画面：云端快照列表（三份，不同时间）。
- 台词要点：
  - Epic 云端存的不是「一个文件夹」，而是**快照 + 分块（chunk + manifest）**。
  - 每次存档上传都是一个完整快照，所以你会看到好几份、时间不同。
  - 工具做的事：把分块下载下来、按 manifest 拼回原始文件。

### 2. 演示（1:30–3:30）完整流程

1. 打开 `SaveGrab.exe`（无 Python 环境也能跑）
2. 点「登录 Epic」→ 打开官方登录页 → 登录 → 复制返回的 JSON → 粘贴 → 登录
   - **录屏时务必把 authorizationCode、邮箱打码**
3. 左边出现游戏库（只显示支持云存档的），比如死亡搁浅、霍格沃茨之遗、极乐迪斯科
4. 选游戏 → 右边列出云端快照（时间倒序）
5. 勾选「同时打包为 ZIP」→ 点「导出选中快照」
6. 进度条跑完 → 「打开目录」→ 展示还原出来的 `autosave0/profile/manualsave` 结构
7. 强调：**全程没有安装游戏**

### 3. 验证（3:30–4:30）真的能用吗

- 如果机器上装了游戏：把导出的文件夹丢进
  `%USERPROFILE%\AppData\LocalLow\KojimaProductions\DeathStranding\<EpicID>\`
  （先关云同步），进游戏看能不能读档。
- 没有游戏也能验证：解压后的文件结构和游戏存档目录一致，且与官方启动器同步下来的文件哈希相同（我实测 51 个文件 SHA256 全一致）。

### 4. 原理（4:30–5:30）

- 一句话：走 Epic 的 `savesync` 接口 + 开源项目 Legendary。
- 画面：简单的流程图（OAuth → 游戏库 metadata → savesync 列表 → 下载分块 → 还原）。
- 提一句：底层 Legendary 是 GPL-3.0 的开源启动器替代品，工具本身也开源。

### 5. 限制与风险（5:30–6:30）—— 这段一定要讲，能减少评论区杠

- 只能导**自己账号**的存档，不能跨账号（死亡搁浅的存档和账号绑定，换号会提示损坏）
- 只对 Epic 目录里配了 `CloudSaveFolder` 的游戏有效，工具会自动过滤
- 用的是非公开接口，Epic 改接口可能失效
- 云端快照可能不是最新的（取决于你最后一次同步），导出前先看清楚时间
- 重要存档多备份几份，别只留一份

## v0.3 新增内容（补拍/加长素材）

如果按 v0.3 录，可以在「演示」段落里加这三段：

1. **快照先看懂再下载**（约 30 秒）
   - 画面：快照列表里有「文件 / 大小 / 内容」三列
   - 台词：「导出前就能看到这份快照有几个手动存档、多大，不用下完才知道拿错了。」
2. **多线程下载对比**（约 20 秒，可选）
   - 把线程从 2 调到 8，展示速度差异；网络差的时候效果更明显。
3. **一键还原 + 自动备份**（重点，约 1 分钟）
   - 先关掉 Epic 云存档同步（画面给个特写）
   - 选一份快照 → 「还原到」下拉框展示自动识别出的目录（Epic 当前账号 / Steam 账号）
   - 点「一键还原选中」→ 确认框 → 进度条 → 弹出「已还原 51 个文件」+ 备份 zip 路径
   - 台词：「还原前它会先把你现有存档打包备份，写错了还能退回去。」
   - **跨平台说明**：「Steam 目录也能选，但账号绑定没变，游戏可能提示存档损坏，这个工具不替你去改 exe。」
